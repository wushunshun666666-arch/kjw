# 参考前端资源

来源：用户指定的 https://jnd68.com/ 于 2026-10-18 公开提供的前端构建资源，以及其公开配置所引用的 https://pc28p.com/ 图片。

此目录是固定快照，`manifest.json` 保存各文件的 SHA-256。保留了原文件中 Vue、Vue Router、Vant 等组件的版权和许可标注。没有自动抓取更新任务。

运行 `python frontend/tools/build_reference.py` 校验快照并生成 `frontend/web/assets1`。构建脚本只处理以下适配：

- 原站 API 调用改为本站 GET 只读接口。
- 路由改为 hash 模式，兼容 Yii2 的 `index.php?r=site/index` 入口。
- 二维码使用本站端点，根据后台登录地址生成，并嵌入后台站点图标；长地址省略中心图标以保证可识别。
- 旧版历史/走势链接映射到相应标签。
- 彩种切换栏位于广告之后、最新开奖之前，独立于广告展开/收起状态；链接由本站服务端安全编码后提供。所有彩种共用常驻首页外壳，普通点击由 `portal-game-navigation.js` 局部加载本站入库数据，保留广告节点、筛选条件和浏览器前进/后退；修饰键点击仍可打开独立页面。
- `portal-reference-bridge.js` 管理首页挂载/卸载和加拿大28轮询启停；其他彩种的展示由 `portal-games.js` 负责。快速切换取消旧请求，晚返回不能覆盖当前彩种，失败保留上一份有效内容。
- 无数据初始状态不显示原构建中写死的示例期号。
- 缺失预测不生成反向组合或虚假的命中/失败标记；轮询等待上次请求完成。
- 联系页原构建把联系网址作为图片地址，实际显示破图；本站保留整宽图片布局，使用后台联系图标（未填则用站点图标），点击跳转联系链接，主链接未填时使用备用链接。

页面的 DOM 模板、CSS、按钮文案、统计计算、咪牌画布和广告交互沿用固定快照。`web/assets1` 是生成目录，修改适配应编辑构建脚本。发布这些同名资源时采用重新验证缓存，不要配置永久 immutable 缓存。

参考站没有提供可维护的 Vue 源码或后台实现；这些资源是浏览器发布版本。后续大幅改版建议整理为自有 Vue 源组件后重新构建。
